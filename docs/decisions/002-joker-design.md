# ADR-002: Дизайн джокеров

**Статус:** Принято  
**Дата:** 2026-08-31

## Контекст

В некоторых вариантах Дурака (колода 54 карты) используются два джокера:
красный и чёрный. Красный джокер бьёт только красные карты, чёрный — только
чёрные. Нужно было решить, как представить джокеры в модели.

## Решение

Джокеры представлены как **комбинация специальной масти и специальных достоинств**:

- Масть: `Suit.JOKER` (отдельная масть для джокеров)
- Достоинства: `Rank.RED_JOKER` и `Rank.BLACK_JOKER`
- Цвет джокера определяется через его достоинство, а не масть

В конструкторе `Card` добавлена валидация: масть `JOKER` может сочетаться
только с джокерными достоинствами, и наоборот.

## Последствия

### Положительные
- Единая модель карты для обычных карт и джокеров
- Цвет джокера доступен через общий метод `Card.getColor()`
- Валидация защищает от невалидных комбинаций

### Отрицательные
- Специальная масть `JOKER` с цветом `NONE` немного усложняет модель

## Альтернативы

1. **Джокер как отдельный класс** — нарушил бы единую модель `Card`
2. **Масть `null` для джокеров** — требует повсеместных проверок на `null`
3. **Только достоинства без специальной масти** — не обеспечивает валидацию
