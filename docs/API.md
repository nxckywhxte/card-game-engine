# Публичный API библиотеки

## 📦 Принцип формирования

Публичный контракт библиотеки формируется по правилу:
- Всё, что находится в модуле **`engine-api`**, — публичный контракт
- Всё, что находится в **`engine-impl`**, — внутренняя реализация
- Модули правил (`engine-rules-*`) предоставляют реализацию `GameRules`

## 🗂️ Планируемые интерфейсы (Фаза 1)

### `Deck` — колода карт

| Метод               | Назначение                     |
|---------------------|--------------------------------|
| `int size()`        | Общее количество карт в колоде |
| `int remaining()`   | Количество оставшихся карт     |
| `boolean isEmpty()` | Пуста ли колода                |
| `Card draw()`       | Взять верхнюю карту            |
| `void shuffle()`    | Перетасовать колоду            |

### `Zone` — зона для карт

| Метод                           | Назначение              |
|---------------------------------|-------------------------|
| `void addCard(Card card)`       | Добавить карту          |
| `boolean removeCard(Card card)` | Удалить карту           |
| `List<Card> getCards()`         | Получить все карты зоны |
| `boolean contains(Card card)`   | Содержится ли карта     |
| `int size()`                    | Количество карт         |

### `Player` — игрок

| Метод                | Назначение               |
|----------------------|--------------------------|
| `String getId()`     | Уникальный идентификатор |
| `String getName()`   | Имя игрока               |
| `Zone getHand()`     | Рука игрока              |
| `boolean hasCards()` | Есть ли карты            |

### `Move` — ход

| Метод                | Назначение     |
|----------------------|----------------|
| `Player getPlayer()` | Кто делает ход |
| `Card getCard()`     | Какая карта    |
| `Zone getSource()`   | Откуда берётся |
| `Zone getTarget()`   | Куда кладётся  |

### `GameState` — состояние игры

| Метод                       | Назначение             |
|-----------------------------|------------------------|
| `List<Player> getPlayers()` | Все игроки             |
| `Player getCurrentPlayer()` | Текущий игрок          |
| `Deck getDeck()`            | Колода                 |
| `boolean isFinished()`      | Игра окончена          |
| `Player getWinner()`        | Победитель (если есть) |

### `GameRules` — правила игры

| Метод                                      | Назначение       |
|--------------------------------------------|------------------|
| `GameState initialize(Deck, List<Player>)` | Начать игру      |
| `boolean validateMove(GameState, Move)`    | Проверить ход    |
| `GameState applyMove(GameState, Move)`     | Применить ход    |
| `Player checkVictory(GameState)`           | Проверить победу |
| `List<Move> getAllowedMoves(GameState)`    | Допустимые ходы  |

## 🚫 Иерархия исключений

Все исключения библиотеки наследуются от базового:

| Исключение                    | Когда возникает                        |
|-------------------------------|----------------------------------------|
| `CardGameException`           | Базовое исключение библиотеки          |
| `InvalidCardException`        | Некорректная карта (невалидный джокер) |
| `EmptyDeckException`          | Попытка взять карту из пустой колоды   |
| `IllegalMoveException`        | Недопустимый ход                       |
| `GameNotInitializedException` | Действие до инициализации игры         |

## 📌 Политика совместимости

- Мы следуем [Semantic Versioning](https://semver.org/)
- До версии `1.0.0` интерфейс может меняться (версии `0.x.x`)
- Начиная с `1.0.0` ломающие изменения — только в мажорных версиях
- Новые методы могут добавляться в минорных версиях
