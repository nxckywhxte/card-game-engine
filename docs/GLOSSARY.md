# Глоссарий

## Карточные термины

| Термин                     | Значение                                                      |
|----------------------------|---------------------------------------------------------------|
| **Масть** (Suit)           | Одна из четырёх категорий карт: червы, бубны, кресты, пики    |
| **Достоинство** (Rank)     | Номинал карты: от двойки до туза                              |
| **Джокер** (Joker)         | Специальная карта наивысшего достоинства (красный или чёрный) |
| **Козырь** (Trump)         | Масть, карты которой бьют карты других мастей                 |
| **Колода** (Deck)          | Набор карт для игры (24, 36, 52 или 54 карты)                 |
| **Отбой / Бита** (Discard) | Стопка сыгранных карт                                         |
| **Кон**                    | Одна партия в Дурака                                          |

## Игры

| Игра                              | Описание                                                   |
|-----------------------------------|------------------------------------------------------------|
| **Дурак** (Durak)                 | Игра на избавление от карт, последний оставшийся — "дурак" |
| **Клондайк / Косынка** (Klondike) | Пасьянс, цель — собрать карты по мастям в фундаменте       |
| **Паук** (Spider)                 | Пасьянс с последовательностями одной масти                 |

## Технические термины

| Термин                         | Значение                                 |
|--------------------------------|------------------------------------------|
| **Иммутабельность**            | Неизменяемость объекта после создания    |
| **Зона** (Zone)                | Любая область для хранения карт в игре   |
| **Ход** (Move)                 | Действие игрока по перемещению карты     |
| **Состояние игры** (GameState) | Полное описание игры в конкретный момент |
| **Правила игры** (GameRules)   | Логика валидации и применения ходов      |
