# Card Game Engine

Модульная библиотека для разработки карточных игр на Java 25.

## 🏗️ Архитектура

Проект построен на принципах **SOLID** и **Dependency Inversion**:

- **engine-core** — базовые сущности (Card, Suit, Rank)
- **engine-api** — интерфейсы и контракты (Zone, Player, GameRules)
- **engine-impl** — стандартная реализация
- **engine-rules-*** — правила конкретных игр (Дурак, Косынка, Паук)

## 🚀 Технологии

- **Java 25** (LTS)
- **Maven** (мультипроектная сборка)
- **JUnit 5** (модульное тестирование)
- **JaCoCo** (покрытие кода)
- **Spotless** (автоформатирование Google Java Format)
- **GitHub Actions** (CI/CD)

## ⚙️ Строгий режим качества

Проект настроен на **максимальную строгость**:

- Компиляция с флагами `-Xlint:all` и `-Werror` (любое предупреждение = ошибка)
- Автоформатирование кода через Spotless
- Параллельная сборка модулей (`-T 1C`)
- Кэширование зависимостей в CI/CD

## 📦 Сборка

```bash
# Клонировать репозиторий
git clone https://github.com/nxckywhxte/card-game-engine.git
cd card-game-engine

# Собрать проект
./mvnw clean verify          # Linux/macOS
.\mvnw.cmd clean verify      # Windows

# Автоматически исправить форматирование
./mvnw spotless:apply
```

- Изучение архитектуры модульных Java-приложений
- Практика строгого CI/CD пайплайна
