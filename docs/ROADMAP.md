## Фаза 0: Фундамент ✅

**Цель:** подготовить инфраструктуру и базовые сущности.

**Выполнено:**
- Мультипроектная структура Maven (6 модулей)
- Строгий режим компиляции (`-Xlint:all`, `-Werror`)
- Автоформатирование (Spotless), покрытие тестами (JaCoCo)
- CI/CD через GitHub Actions, Git-хуки
- Модуль `engine-core`: `Suit`, `Rank`, `Card` с полной поддержкой джокеров
- Покрытие тестами базовых сущностей 100%

## Фаза 1: Ядро библиотеки 🔜

**Цель:** определить стабильный публичный контракт библиотеки.

**Задачи:**
1. Интерфейсы `engine-api`:
    - `Deck` — колода (размер, тасование, взятие карт)
    - `Zone` — зона для карт (рука, стол, сброс, фундамент)
    - `Player` — игрок с рукой карт
    - `Move` — ход (действие с картой)
    - `GameState` — состояние игры
    - `GameRules` — правила игры
2. Иерархия исключений библиотеки (см. [API](API.md))
3. Стандартная реализация `engine-impl`:
    - `StandardDeck` с фабрикой для колод 24/36/52/54 карты
    - `StandardZone`, `StandardPlayer`, `StandardMove`, `StandardGameState`

**Критерии готовности:**
- [ ] Все интерфейсы имеют Javadoc с примерами
- [ ] Покрытие тестами ≥ 95% для `engine-core` и `engine-impl`
- [ ] Нет предупреждений от `-Xlint:all -Werror`
- [ ] Собран снапшот артефакта

## Фаза 2: Первая игра ⏳

**Цель:** проверить архитектуру на реальной игре.

**Выбор игры:** Клондайк (Косынка) — самая простая логика для проверки архитектуры.

**Задачи:**
1. Модуль `engine-rules-klondike`
2. `KlondikeRules implements GameRules`
3. Специфичное состояние: табло, фундамент, колода, сброс
4. Правила перемещения и условие победы

**Критерии готовности:**
- [ ] Партия в Клондайк играется программно (через тесты)
- [ ] Покрытие тестами правил ≥ 90%

## Фаза 3: Сложные игры ⏳

**Цель:** доказать универсальность движка на играх со сложной логикой.

**Задачи:**
1. `engine-rules-spider` — Паук (2 колоды, последовательности одной масти)
2. `engine-rules-durak` — Дурак (козырь, атака/отбой, джокеры)

**Критерии готовности:**
- [ ] Все три игры работают через единый интерфейс `GameRules`
- [ ] Правила Дурака корректно обрабатывают джокеры (красный бьёт красные, чёрный — чёрные)
