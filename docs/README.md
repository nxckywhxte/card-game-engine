## Быстрый старт для читателя

1. Начни с [Архитектуры](ARCHITECTURE.md), чтобы понять структуру;
2. Изучи [План разработки](ROADMAP.md), чтобы увидеть текущий статус;
3. Посмотри [Примеры использования](USAGE.md), чтобы понять ценность;
4. Загляни в [Решения](decisions/README.md), чтобы понять, почему всё устроено именно так.

## 📝 Соглашения по документации

- Диаграммы выполнены в формате **Mermaid**
- Архитектурные решения фиксируются в формате **ADR** (Architecture Decision Records)
- Документация обновляется вместе с кодом (правило "код и документация в одном коммите")
