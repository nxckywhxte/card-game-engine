# Архитектурные решения (ADR)

В этой папке зафиксированы ключевые архитектурные решения проекта в формате
**ADR (Architecture Decision Records)**. Каждое решение документирует контекст,
выбранный вариант и его последствия.

## 📋 Формат

Каждый ADR содержит:
- **Статус** (Принято / Отклонено / Устарело)
- **Дату** принятия решения
- **Контекст** (проблему, которую решали)
- **Решение** (что выбрали)
- **Последствия** (плюсы и минусы)
- **Альтернативы** (что рассматривали)
